**2.0.3 修复与验收记录 · 2026-10-24**

本次修复基于当前工作区，保留并纳入原有模块拆分、测试和 CI 调整。应用版本为 2.0.3，存档 schema 为 6，已有棋谱默认迁移为 simplified-v1 裁决规则。

| 审查问题 | 本轮处理 |
| --- | --- |
| 语义损坏的库覆盖正常备份 | 读取及事务提交验证 FEN、历史和终局依据，按完整内容缓存验证；损坏时拒绝写入并保留有效备份 |
| 管道故障测试假通过 | 根据实际模块路径启动夹具，先收到故障模式确认；半行、持续噪声、满管道与取消真实执行 |
| 导入成功数量与保留数量不符 | 容量不足整体拒绝，不淘汰现有棋谱、不建立误导的删除屏障 |
| Android 发布签名不稳定 | 使用用户提供的正式密钥，仓库外保存；四项加密 Actions Secrets 已配置并核验；每包验证实际证书、版本、非调试属性和 SHA256 |
| 旧缓存覆盖更深分析 | 仅载入有效且更深的缓存，保留本会话同深度的新结果及规则终局分值 |
| 收藏旧重试重新翻转 | UI 使用带修订号的目标状态；冲突保护新操作；旧操作 ID 兼容去重不再在 128 项后失效 |
| 字体预热密度错误、首次对局缓存卡顿 | 共用画布计算，按实际密度预热；启动时预备棋盘与棋子缓存 |
| 连续设置补丁积压 | 合并相邻补丁、保留每次请求确认及显式改回初值的意图；保留事务顺序边界 |
| 主存档损坏后声音偏好回退 | 提供独立偏好读取，启动恢复页保留已读到的设置 |
| 无障碍节点随滚动和缩放变化 | 显式业务身份与显示矩形分离，棋盘格、归档和旧对局控件使用稳定身份 |
| 长期删除记录与离线继承边界 | 删除明细限制 4096 项，并保留身份时间屏障；旧窗口不能自动复活记录，新分支仍可保存；继承证明上限扩展为最大棋谱步数的四倍 |
| 规则升级影响旧局重放 | 存档记录 ruleset，拒绝不支持的未来裁决版本；当前规则行为保持稳定 |
| 多个退出标志相互依赖 | 提取 CloseState 状态机；必须收到本次关闭的刷新确认，并等待对局保存完成 |
| 静止与后台唤醒 | Windows/Android 使用事件循环与有界任务计时，暂停期间停止绘制唤醒；Apple/Linux 行为保留现有路径，待平台验收 |
| 性能缺少定位指标 | 增加排队、锁等待、语义读取验证、序列化、写入、sync、替换及棋盘预缓存计时 |
| 本地检查与 CI 范围不一致 | check.ps1 运行全部 Python 工具回归和独立混音测试；工作流语法通过 actionlint |
| 发布混入未签名或验证包 | 发布资产仅接受 Windows 便携包和正式签名 Android APK；iOS 未签名/模拟器产物单独保留为验证附件；正式 tag 完整检查后生成正式 Release |

本机已通过格式、严格 Clippy、116 项 Rust 测试（另有 1 项仅供子进程调用的忽略夹具）、25 项 Python 工具测试、3 项独立混音测试、下载校验/镜像回退回归、51 个真实引擎局面差分、10,000 个变异输入样本、29 个 UI 场景与视觉基线。

Windows 真实输入回归已通过鼠标落子、UIA 焦点与键盘调用、保存失败后的重试、中文提交、窗口关闭保存、冷启动续局，以及 Ctrl+Q 不误退出。中文提交不能替代真实拼音组合输入或读屏人工验收。

两个 Android ABI 已在本机完成正式签名构建，证书与提供的备份一致。本机没有 Android Emulator 虚拟化驱动，未为运行测试修改系统驱动；Android 模拟器和 Apple 平台验收需要对应 CI/设备结果。仓库原有未提交修改与本轮修复一起进入独立修复分支，用于跨平台验证。

性能原始样本和本机日志保存在 `target/release-validation-203/`。只有实际完成的检查列为通过。真实设备读屏、输入法组合、耗电/热稳定性，以及 Apple 正式签名不属于已完成的本机验收。
